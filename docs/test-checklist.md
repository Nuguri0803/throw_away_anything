# Test Checklist

배터리 연결은 가장 마지막에 합니다. 전원 투입 전에는 반드시 + / - 쇼트 여부를 확인합니다.

## 단독 테스트 순서

- [ ] 5V 벅 컨버터 출력 확인
- [ ] Arduino 단독 업로드 확인
- [ ] RGB LED 단독 테스트
- [ ] 팬 단독 테스트
- [ ] 24V 승압 컨버터 출력 확인
- [ ] BTS7960 + 모터 1개 단독 테스트
- [ ] 모터 2개 동시 테스트
- [ ] 13V 승압 컨버터 출력 확인
- [ ] 열선 + MOSFET 단독 테스트
- [ ] 열선 PWM 값 조정
- [ ] 전체 자동 시퀀스 테스트

## 이상 발생 시 즉시 중지

- 타는 냄새
- 컨버터 과열
- MOSFET 과열
- 배선 피복 변형
- 배터리 전압 급락
- 모터가 멈춘 상태에서 계속 전류가 흐르는 상황

## LiPo 관리

- 충전과 방전을 동시에 하지 않습니다.
- 충전 시 장치에서 분리하고 전용 밸런스 충전기를 사용합니다.
- 3S LiPo 만충 전압은 12.6V입니다.
- 전체 전압 약 9.9V 근처부터 저전압 보호가 필요합니다.
- 셀당 3.0V 이하 방전은 위험합니다.
